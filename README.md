# The Burger

Este projeto consiste em uma landing page responsiva desenvolvida com HTML, CSS e JavaScript. O objetivo foi criar uma interface moderna e agradável, utilizando Flexbox para organização do layout, Media Queries para adaptação em diferentes dispositivos e um menu mobile interativo.
